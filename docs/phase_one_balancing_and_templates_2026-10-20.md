# 本阶段任务均衡、模板轮转与分阶段调度

更新：2026-10-21。状态：**新方案设计/配置/prompt草案已落库，生产堆调度器和状态服务未实现。** 当前主合同见[小根堆评估与完整设计](task_heap_scheduler_evaluation_2026-10-21.md)，替代旧的全部task预分配/非均匀软权重方案。

## 1. General先适配2条，再均衡最多3条

先一次模型请求从启用白名单中选最适配task、生成最多2个QA，先入账；再逐次从task小根堆取有效供给最少者，争取生成最多3个QA。第一阶段不足不回填。Long建议单独task堆、全部3个均衡生成额度，不擅自给Long增设fit阶段。

## 2. 状态和比例

每分支权威字典保存passed/pending_generated/reserved及累计生成、拒绝、弃答；堆按前三者之和排序。默认分支内task等量，旧注册表5/10/20权重仅保留为历史建议。语言/题型用两分支共享的全批次边际缺口，MCQ选项数只以MCQ为分母。均衡不是精确保证；2个自由适配QA若持续集中在同一task，3个均衡QA可能无法补平。

## 3. 弃答可以改派，QA拒绝不能回填

未产QA且明确task_inapplicable/evidence_exhausted时，当前视频屏蔽该task再取下一个；form_inapplicable只屏蔽该语言/题型/选项组合，不能误判整个task无效。不得重复已弃答组合；建议均衡尝试预算T+K，任务/组合耗尽或预算结束就少产。技术错误不按语义弃答处理，不循环换task调用API。

一个QA一旦产出就消耗阶段额度，其后质量拒绝不回填。所有最终质量合格者保留，不能为配额丢弃。真实预算仍待提供，设计本身不启动付费请求。

## 4. Prompt与历史示例

新请求使用[阶段prompt](../prompts/task_scheduler/README.md)：fit请求最多2槽、task由模型选择；balance请求1槽、task固定。事实提取仍并入同次QA请求，不增加事件标注API/A4/A10。旧单批5/3请求仅作历史示例，不是当前调度器运行入口。模板库与审核原则继续沿用下文。

## 5. 模板库：本轮交付192个中英文种子模板

实际文件：[question_templates.json](../configs/question_templates.json)。12个启用任务 × 每任务8种表达/关注方式 × 中英双语 = **192个种子模板**。每条兼容 OE 与 MCQ，共384种“模板×题型”组合；384不是独立措辞数，模板数也不是语义多样性的验证结果。

每条含 `template_id/task/language/stem/required_slots/supported_question_types/answer_styles`。占位槽位必须由已存在的 caption 事实填充；`time_ref` 由程序将绝对时间锚渲染为自然措辞。不能由模板暗示正确选项、添加未观察对象或把“为什么”自动包装成因果。

特别地，`evidence_a/evidence_b/segment_a/segment_b` 在**问题文本中只能填不泄露结论的片段指代线索**，例如“开始装盘的片段”，不能填“开始用红盘、结束用蓝盘”后再问盘子如何变化。完整事实放外部证据账本供生成/审核，不直接抄进问题。`relation_query`只填待求关系；如果问法本身给出答案或无需视频即可解出，A7拒绝。这是模板实现时必须防的标签泄露风险。

轮转键为 task×language×question_type；优先少用模板，同视频避免重复，固定 seed 保证可复现。候选生成的**同一请求**完成槽位填充与小幅改写，保存模板种子和最终问法，之后才进入 A7。审核后不再改题。MCQ 选项由结构化事实构造，要求同一语义维度、互不等价、唯一正确、干扰项不靠语法/长度泄露；3/4/6选项数由程序分配。选项位置用固定随机 seed 打乱并同步更新字母答案，不混淆成多选。

答案使用多种自然表达：短事实、完整句、对比句、按序概述等，但要服从问题需求与语言，不强行把所有答案写成长段解释。没有证据的细节不能为“丰富表达”补进答案。MCQ 最终 assistant 仍只输出单字母，解释不混入答案字段。

模板防重复采用本地规范化文本、n-gram/MinHash 或字符相似度，不接 A10。报告最常用模板占比、有效模板数、标准化问法重复率、答案长度/开头分布、选项字母分布、各任务证据覆盖及人审结论。本地相似度只能筛表面重复，不能保证语义去重；这项限制必须保留在报告中。

## 6. 不新增独立 API 的接口约束

参考实现提示见 [task_generation.md](../prompts/task_generation.md) 与 [quality_audit.md](../prompts/quality_audit.md)。它们是**提示合同草案**，尚非经过真实模型调优的可用生产 prompt。

- A3-fit让模型在白名单内选task；A3/A5-balance接收堆选定的固定task，不能自行换类别。
- 不足返回 `abstain`，禁止附带猜测答案。
- 不新增模板改写 API；改写在生成请求中一次完成。
- A7 同一次请求同时判断支持性、答案、选项唯一性、task 与语言/时序要求；一次综合判断不等于保证每项都能可靠判断。
- caption 门禁是 QA 生成前独立的 C_GATE，不是恢复 A4，也不计为逐题 A7。
