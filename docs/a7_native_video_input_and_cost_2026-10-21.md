# A7澄清：直接发送原视频与对应文本，撤回256张图片成本基线

日期：2026-10-21。基线：`db973bcd204474c84a189dc6af13c8a8e53aae54`。本轮只更新设计、离线计算器与合同校验，没有访问用户媒体、上传或调用模型API。

**用户明确A7是直接把视频和对应文本发送给Qwen3.8-Flash。当前合同据此设为：每题一次“原始完整视频文件/URL＋该题审核文本”，由API处理视频。此前每题256张1080p独立图片是助手自设的估算假设，不能继续代表用户方案；3.38元只保留为历史图片方案对照。**

## 1. 一次实际发送什么

- 一份原始完整MP4文件或API可读取的原片URL；不是自行抽出的256张独立图片，也不是仅候选引用片段。
- 同请求中的审核指令、该题问题、答案/选项、task、绝对时间基准与必要事实引用。
- 一次返回综合审核结论；不拆成事实/答案/选项多次调用，不审核后再补看或修答案。

按现有逐题合同，8条QA均送审时最多8次视频推理；不擅自改成8题合审一次。上传/URL复用可减少传输，但不自动使其余7次推理的视觉输入免费，缓存折扣以真实命中与供应商账单为准。

输入形式已澄清；实际生产API/密钥/部署、FPS、有效帧上限、像素与思考参数仍未冻结。Qwen3.8-Flash是本轮指定估算模型，不自动填成全项目所有角色的生产模型。

## 2. 一小时整片不能套用10/30秒的resize结论

若按API默认2FPS作目标，一小时对应7,200个采样时刻；实际是否全部有效、是否触发服务帧上限，需要核对所选接口与模型，不报告为实测结果。通用视觉示例的旧模型2,000帧常量不能直接移植到Qwen3.8-Flash。

型号专属[API参考](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)列出默认视频max_pixels=655360、total_pixels=819200000，并将后者描述为对应800000个图像token。整片采样很多帧时，总像素预算会参与resize，因此不能声称所有帧仍保留L1/L2短片推算的1056×576。

这里还有待核实的文档口径：API文字将total_pixels描述为所有帧面积之和，而[通用视觉估算示例](https://help.aliyun.com/zh/model-studio/vision)在尺寸预算中使用FRAME_FACTOR=2，并在最终token公式中除以两帧分组。示例含旧模型常量，不能直接拼接新型号参数就把整片精确分辨率/实际token报为已确认。此前短片未触发总预算，因此这一分歧不改变其条件计算。

本轮不以未经核实的固定resize给A7报唯一预测价；以下直接给出明确的视觉token用量/预约情景。800K是预算算例，并非已证明的账单硬上限，也不是“上传视频必定收费800K”。

## 3. A7费用按视觉token用量计算

沿用北京实时按量原价，输入0.8元/百万token、输出2.7元/百万token；不扣免费额度/缓存/Batch折扣。[官方价格](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)。

设每次视频视觉输入为V个token，继续仅为算例保留每题文字输入2000、可见输出1000token，并关闭内部思考：

```text
单题费用 = (V + 2000) × 0.8 / 1M + 1000 × 2.7 / 1M
         = V × 0.8 / 1M + 0.0043元
```

| 每题视觉token用量情景 | A7单题/元 | 8题A7合计/元 | 替换旧A7后全链路合计/元 |
|---|---:|---:|---:|
| 100,000 | 0.0843 | 0.6744 | 8.9510 |
| 400,000 | 0.3243 | 2.5944 | 10.8710 |
| 800,000预算算例 | 0.6443 | **5.1544** | **13.4310** |

**这三行是用量情景，不是实际费用范围或经验均值。** 必须用实际响应usage替换V；实际文字、输出、额外标记与思考也需要计费。文件大小/时长不直接等于V。

全链路列仅用于保持与上一轮可比：L1/L2仍按2FPS短视频默认像素档，其他非A7阶段假设不变。非A7部分合计8.2765988元，C_GATE仍暂沿用128张图片的历史估算，本次没有把C_GATE也改成整片视频。

所以，按800K预算算例：

```text
调用数：360 L1 + 120 L2 + 1 C_GATE + 7生成 + 8 A7 = 496
费用：8.2765988 + 5.1544 = 13.4309988元，约13.43元
```

如果496次平均每次额外产生4096个计费思考token，另加5.4853632元，合计约18.92元。这仍是额外用量假设，不是默认思考长度；模型默认开启思考，见[官方说明](https://help.aliyun.com/zh/model-studio/deep-thinking)。

直接传整片不保证比256张图片更便宜：视频编码可能更省，但实际看到的时间范围和采样数量也可能更大。这里不能仅因为输入类型变成video就声称审核费用一定下降。

## 4. 设计更新和核验状态

配置模板增加audit_input_mode=native_video_file_plus_text、audit_media_scope=original_full_video，采样profile仍null；四模块大纲、决策和质量审核prompt统一为原片＋文本。校验器防止重新把独立图片默认当作A7输入合同。最终训练JSON仍是12字段，调用/采样/账单外置。

离线计算器新增CURRENT_A7_NATIVE_VIDEO用量情景，原有图片价格保留且标为历史对照；不将0.6443或800K写进生产限额，不执行接入校准。相关脚本：[估算器](../scripts/estimate_one_hour_qwen38_cost.py)、[设计校验](../scripts/validate_design.py)。

本地核验：设计校验器、16项设计测试、9项调度合同测试通过；A7输入字段、800K情景的Decimal算术及本文本地链接通过。它们不验证真实视频预处理、账单或审核准确率。

后续先冻结所选API的视频采样/像素、文字/输出/思考上限，再在另列预算的接入验证中核对usage与服务行为。接口不返回的有效帧/resize元数据必须标unknown；质量失败仍reject，不加审核次数或自动返工。
